# God Weapons (Fabric, Minecraft 1.21.11)

Void Reaper, Godslayer and Celestial Judgement.

## Build with GitHub (no local setup)
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the **Actions** tab. The "Build mod" workflow runs on every push.
3. When it's green, open the run and download the **godweapons-1.21.11** artifact. The jar inside goes in your `mods` folder.

Needs Fabric Loader 0.18+ and Fabric API for 1.21.11 on the player/server side.
